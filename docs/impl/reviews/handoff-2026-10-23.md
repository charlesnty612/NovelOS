## 5. 开工前必读的三条纪律（本会话踩过的）

1. **突变执行器在飞时禁一切源码读写与 git 操作**（本会话我犯过一次：执行器在飞时跑了 `git status`/指纹）。判断是否在飞：`Get-ChildItem -Recurse -Filter '*.mutbak*'` 非空 ⇒ 等；中断后**不能凭日志**判断（日志最后一行「还原校验 OK」说的是上一条）⇒ 必须 `.mutbak` 与源文件 `cmp`。
2. **`run_spec --changed` 新语义（批次二十九起）**：目标源文件 **∪ 规格文件本身**。新增规格会被跑到；输出含 `[增量] 目标文件命中 N / 规格文件命中 M ⇒ 合计 U`。**不要**退回只看目标文件的旧口径。
3. **每次收尾闸门固定六步**：`tree_fingerprint`（前）→ `ruff` → `pytest -n 20 -q` → `tree_fingerprint`（后，须逐位一致）→ `validate_specs` + `run_spec --all --changed --precheck` 再实跑 → 查 `.mutbak*` 残留。
