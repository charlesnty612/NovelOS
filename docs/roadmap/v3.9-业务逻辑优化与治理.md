# V3.9 业务逻辑优化与治理计划（2026-09-13 制定）

> 依据：三路线程并行代码级审查（章节生产四工作流链路 / 上下文引擎装配 / 质量引擎与提交闭环），
> 所有论断经主会话逐条复核并带 file:line 证据。原则沿用 V3.7~V3.9 计划：**闭环无候选项**——
> 每项要么落地、要么经评估给出不做裁决并留痕。
> 定位重申（2026-09-11 用户裁决）：纯自用工具，不跟风对外分发能力。

## 一、问题总览

主链路骨架（plan→write→review→commit 的事务、幂等、回滚）健康，但审查发现：

- **P1 正确性 bug ×2**：condense 字数压缩生产不可达；装配缓存键缺维度导致脏命中
- **确定性缺陷 ×4**：scene_word_budget 崩溃路径、save_draft 字数断链、observer「最近 5 条」
  按随机 id 排序、leg 元数据 rowid 序不稳定
- **体系级设计债 ×3**：质量评分悬崖聚合、失败闭环断头（gate 阻断无出路）、上下文无 token 预算兜底
